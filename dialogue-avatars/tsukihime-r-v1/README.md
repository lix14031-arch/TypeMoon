# 月姬对白头像

22 名角色、23 套形象、138 组表情。每人固定六种，爱尔奎特日常与长发真祖公主各六种。

爱尔奎特形态只按剧情已明确的形态选择，不由喜怒情绪切换；罗亚与四季分别匹配；尼禄·卡欧斯不复用 Fate 尼禄的短名键。未公开身份不输出专属头像。作品完整 JSON 与私人聊天未上传。

## CSS兼容

只修改 built_in_css，主提示词、世界书和输出模板与已接受版本完全一致。中文 data-portrait 优先，中文 data-speaker 白名单可回退识别。CSS不分析台词语义；有效 data-face 对应六表情，缺失或非法值回退平静。已有头像按钮使用悬停/聚焦预览；没有按钮时用纯CSS补出头像，桌面悬停整段对白预览。不会生成表情切换按钮。
